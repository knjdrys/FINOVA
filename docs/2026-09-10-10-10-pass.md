Goal: raise every scorecard item from the 8.5/10 audit to 10/10.

## What changed

### New-user experience (no more "figure it out yourself")
- First launch auto-suggests loading **demo data**; demo dates are generated
  *relative to today* (`buildDemoState(todayISO)`), so Home is never empty and
  never stale. State is a pure function of `todayISO` — the wall-clock
  dependency was removed (used to make `createdAt/updatedAt` non-reproducible).
- **Settings → Learn** section: animated guided tour + full app guide, both one
  tap away.
- **Auth screen**: guest mode promoted to the primary dark CTA when no Supabase
  is configured — "Start as Guest (no account needed)" above the email form.

### Sorting & grouping (every list)
- **Budgets** — by spending, most used first.
- **Bills** — unsettled first, then due date; new *Hide settled* toggle.
- **Recurring** — by next occurrence, active first.
- **Goals** — by target date, soonest first.
- **Transaction timelines** (Home + All Expenses) — grouped **by day AND by
  category** via new `src/domain/transaction/DayGrouping.ts`; a busy day reads
  like a receipt ("Food • 3 items • ₱810"). Quiet days stay compact
  (single-item categories render without a header).

### UI/UX overhaul
- **Settings rebuilt** into 7 labeled sections: Profile / Money / Accounts /
  Preferences / Security / Learn / Data. Live 15-day payroll cycle card,
  destructive (rose) Start-Fresh, sample data moved to Data section.
- **Full i18n (EN + FIL)** for Plans, Settings, and Auth — 44 auth keys, 43
  settings keys, 32 plans keys added to both locales; locale-parity test now
  covers all of them (a missing FIL key fails the build).
